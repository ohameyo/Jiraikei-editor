# Lab 测试版脚标

## 优先级
P1。

## 背景
Cloudflare Pages lab 测试地址需要在页面上有轻量标识，方便和正式版本区分。

## 已做修改
- 页面新增 `LAB` 脚标。
- 脚标固定在画布框右下角，使用半透明小胶囊样式。
- 脚标设置 `pointer-events: none`，不拦截页面工具栏、画布和导出操作。
- 移动端脚标压缩宽度并适配安全区，降低遮挡风险。
- 根据线上反馈调整：移动端脚标改为固定右上角，避开底部工具栏和浏览器底栏，并提高不透明度确保可见。
- 根据手机端反馈再次调整：脚标从屏幕固定定位移入画布框右下角，仅显示 `LAB`，避免遮挡功能区。
- 根据截图红框位置再次调整：脚标从画布框内部移到 `canvas-stage` 右下角空白区域，位于画布框外侧。
- 脚标改为仅在 `jirai-editor-ux-lab` 域名显示，正式版隐藏，避免测试标识进入正式页面。

## 修改文件
- `index.html`
- `styles.css`

## 验证
```sh
node --check src/app.js
git diff --check
```

验证结果：通过。

## 遗留风险
- 脚标位于画布区域右下角空白处；不同手机宽度下画布外侧空白宽度不同，仍需真机确认不会贴近底部功能 tab。
