# 移动端画布与功能区布局整理

## 优先级
P1。

## 背景
移动端需要类似修图 App：画布占比高，功能区简洁，子功能按需出现。

## 当前问题
- 子功能 tab 和参数区容易挤压画布。
- 某些功能区内容为空时可能露出不一致色块。
- 贴纸、预设、胶囊按钮需要保持小巧精致。

## 相关文件
- `index.html`
- `styles.css`
- `src/app.js`

## 已做修改
- 移动端画布固定。
- 功能 tab 高度缩小。
- 预设胶囊和贴纸排列做过压缩。
- 去掉移动端重复上传 tab。

## 验收标准
- 移动端首屏画布占比足够高。
- 功能区不横向滑动。
- 子功能只在母功能选中后出现。
- 空功能区不露出异常色块。
