# 顶部工具栏与前后对比交互

## 优先级
P1。

## 背景
移动端顶部工具栏需要左侧四个操作按钮，右侧一个前后对比按钮，并保持分组清晰。

## 当前问题
- 顶部胶囊需要更小巧。
- 左四按钮与右侧对比按钮之间要有明显间隔。
- 前后对比点击和长按逻辑曾出现瞬间弹回或松手后误触双图。

## 相关文件
- `index.html`
- `styles.css`
- `src/app.js`

## 关键代码/变量
- `compareMode`
- `comparePeekOriginal`
- `compareLongPressTimer`
- `COMPARE_LONG_PRESS_MS`
- `els.compareBtn`

## 已做修改
- 移动端按钮文案缩短为“清空”“恢复”。
- 顶部胶囊缩小并拉开对比按钮间距。
- 前后对比区分点击与长按。

## 验收标准
- 清空/恢复文字居中且不溢出。
- 左四按钮和右一按钮视觉分组明确。
- 点击前后对比保持双图状态。
- 长按仅临时查看原图，松手恢复，不误触双图。
