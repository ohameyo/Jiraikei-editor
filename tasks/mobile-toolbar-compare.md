# 顶部工具栏与前后对比交互

## 优先级
P1。

## 背景
移动端顶部工具栏需要左侧四个操作按钮，右侧一个前后对比按钮，并保持分组清晰。

## 当前问题
- 顶部胶囊需要更小巧。
- 左四按钮与右侧对比按钮之间要有明显间隔。
- 前后对比点击和长按逻辑曾出现瞬间弹回或松手后误触双图。
- 前后对比需要支持三段点击状态：带 BEFORE/AFTER 文字的对比图、不带文字的对比图、回到正常编辑图。

## 已做修改
- 移动端按钮文案缩短为“清空”“恢复”。
- 顶部胶囊缩小并拉开对比按钮间距。
- 前后对比区分点击与长按。
- 前后对比点击循环改为：带文字对比 -> 无文字对比 -> 正常编辑图。
- 导出对比图跟随当前 `compareLabels` 状态，支持无 BEFORE/AFTER 文字版本。
- 平板/移动端工具栏改为用 `margin-left: auto` 把前后对比按钮推到右侧，减少右侧空白边距。

## 验收标准
- 清空/恢复文字居中且不溢出。
- 左四按钮和右一按钮视觉分组明确。
- 前后对比按钮贴近工具栏右侧，不留下明显空白。
- 点击前后对比保持双图状态。
- 第一次点击显示带 BEFORE/AFTER 文字的对比图。
- 第二次点击保持双图但隐藏 BEFORE/AFTER 文字。
- 第三次点击回到正常编辑图。
- 长按仅临时查看原图，松手恢复，不误触双图。
