# 正式版拍立得与画布一致性

## 优先级
P1。

## 背景
拍立得功能需要作为正式版素材上线，支持 PC 与移动端添加、横竖切换、照片缩放、拖动定位、预览和导出一致。

## 当前问题
- 弹窗预览为性能使用缩小后的滤镜图，确认后正式渲染使用全尺寸滤镜图，缩放参数未换算时会造成预览和最终画面不一致。
- 横版拍立得仍使用竖向预览画布，横版框在弹窗里显示偏小，操作空间不稳定。
- 弹窗拖动未限制起点，用户可能在边框或留白区域误触拖动照片。
- 拍立得资源应保持横竖两套正式 PNG，样式和入口可直接上线。

## 已做修改
- 新增横版和竖版拍立得正式 PNG 配置，拍立得入口放入贴纸面板。
- 拍立得弹窗按当前边框比例同步 canvas 尺寸，竖版为竖向预览，横版为横向预览。
- 确认拍立得时把缩小预览图上的 `scale` 换算到全尺寸 `photoCanvas`，再做边界 clamp，修复预览与导出缩放不一致。
- 点击当前已启用的同一个拍立得边框时，会把现有全尺寸 `photoTransform` 换算回弹窗预览源图，支持返修位置和缩放。
- 拍立得已启用时，面板新增 `调整照片位置` 显式入口，打开当前横/竖框的返修弹窗并保留已有缩放与偏移。
- `调整照片位置` 和 `关闭拍立得` 改为同一行小按钮，减少已启用状态下的面板占用。
- `调整照片位置` 改为普通操作按钮样式，不再使用类似已选中的深色状态。
- 新增独立 `拍立得` tab，放在 `贴纸` tab 后面；拍立得边框、调整位置和关闭入口均迁移到该 tab，贴纸 tab 只保留贴纸内容。
- 拍立得面板副文案从 `照片边框` 改为 `拍立得加工`。
- 移动端底部工具栏改为 7 等分，并压紧图标与文字字号，修复新增拍立得 tab 后 `导出` tab 被挤出的问题。
- 关闭拍立得前会先记录当前拍立得状态到历史栈，修复点击 `关闭拍立得` 后再点 `返回` 无法恢复拍立得效果的问题。
- 撤销/重做恢复快照后会清空预览缓存并递增渲染 token，避免拍立得关闭/恢复时状态已恢复但画布沿用旧缓存。
- 拍立得拖动仅在照片窗口内起效，减少点到边框、阴影、留白时误移动照片。
- 预览 canvas 增加稳定背景、grab/grabbing 光标、`display: block` 和容器裁切，减少移动端适配抖动。
- 拍立得缩略按钮调整为正式版 8px 圆角、稳定缩略图尺寸和溢出裁切。
- 线上测试反馈后补修：拍立得弹窗打开时先显示弹窗和稳定底色，并触发画布「加工中」提示，避免滤镜预览图和边框资源加载期间无反馈。
- 拍立得边框资源增加空闲预热，进入拍立得 tab 时也会预热横竖两张 PNG，降低首次打开预览等待。
- 拍立得 tab 的边框按钮改用独立轻量预览图 `assets/polaroid_frame_previews/*`，页面 head 预加载两张 8KB 缩略图；弹窗和导出仍使用原始边框 PNG。
- 拍立得启用后，后续贴纸、文字、马赛克图层统一裁切在拍立得照片窗口内，避免导出时元素悬浮到照片外或白边外。
- 根据线上截图反馈修正：拍立得启用后的元素裁切范围从照片窗口改为整张拍立得边框，允许贴纸/文字显示在白边上，只裁掉拍立得整体外的部分。
- 拍立得启用后再次编辑腮红，会刷新内部 `photoCanvas` 并使用拍立得照片显示映射绘制腮红预览/选区，避免二次编辑无效或位置错位。
- 拍立得启用后编辑滤镜/HSL 时不再使用整张 canvas CSS 近似预览，滤镜滑杆改为实时提交真实滤镜并刷新拍立得内部 `photoCanvas`，避免用户感觉原图滤镜无法编辑。
- 根据线上反馈回调：拍立得启用时导出不再保留原图画布尺寸，而是从整张预览画布裁出拍立得边框区域，并输出为拍立得素材自身尺寸；竖版导出为 `705x1111`，横版导出为 `1111x705`。
- 拍立得调整弹窗改为两段式预览：打开时立即用当前原图/已有拍立得图绘制可见预览，框图和滤镜后的照片异步完成后再替换，避免滤镜图或边框资源生成期间只显示空白底色。

## 验收标准
- PC 和移动端均可看到横竖拍立得入口。
- 横竖拍立得弹窗预览比例与素材比例一致。
- 照片缩放、拖动、重置后不会露出空白。
- 确认后的画布预览与导出使用同一套拍立得渲染路径。
- 拍立得启用后导出图片尺寸等于拍立得边框素材尺寸，而不是原图画布尺寸。
- 禁用拍立得可回到添加拍立得前的编辑状态。

## 遗留风险
- 本轮未通过真实手机相册上传完整跑通，因为浏览器自动化环境不便操作系统文件选择器；仍需真机 Safari/微信内置浏览器复测上传、拖动、确认和长按保存。
- 拍立得 PNG 自身的边框、阴影、留白效果依赖当前素材；若后续替换素材，需要同步校准 `photoWindow` 坐标。
- 仍需在 Cloudflare 测试地址用真实图片确认「加工中」出现时机和拍立得弹窗首开耗时。
