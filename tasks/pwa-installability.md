# PWA 安装、离线和缓存试验

## 优先级
P2，需在 Web 核心体验稳定后推进。

## 任务目的
低成本验证 Jirai-editor 是否适合通过 PWA 提供轻 App 体验，包括安装图标、离线打开、静态资源缓存和更新策略。

## 前置条件
- P0 丝滑性和滤镜渲染性能基本稳定。
- 资源体积和缓存策略已完成。
- 已有移动端浏览器验收基线。

## 范围
- Web App Manifest。
- App 图标和启动体验。
- Service Worker 缓存静态资源。
- 离线兜底页或离线打开策略。
- 缓存更新和版本失效。
- iOS Safari、Android Chrome、内嵌浏览器限制记录。

## 验收标准
- PWA 试验版可安装，不影响普通网页访问。
- 离线策略不会导致旧代码和旧资源长期混用。
- 明确 PWA 能解决的问题和不能解决的问题。
