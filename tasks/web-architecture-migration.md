# Web 生产入口与模块化迁移计划

## 优先级
P1，承接「网页制作方向与 App 封装方案」。

## 任务目的
厘清当前 Web 生产入口和模块化文件之间的关系，制定低风险迁移计划，避免后续功能继续堆进 `src/app.js`。

## 当前观察
- `index.html` 当前直接加载 `src/app.js`。
- `src/app.js` 是实际主逻辑，约 5700 行。
- `src/main.js`、`src/core/store.js`、`src/modules/*`、`src/ui/controls.js` 已存在，但当前不是生产入口，且实现与 `src/app.js` 有代差。

## 范围
- 明确短期生产入口仍以 `src/app.js` 为准。
- 标记旧模块哪些可复用、哪些应废弃或重写。
- 设计迁移顺序：配置和纯函数 -> 渲染管线 -> overlay/UI -> 状态管理 -> 入口切换。
- 评估是否引入 Vite/ESM 构建流程。
- 建立迁移期间的验证方式。

## 验收标准
- 形成模块边界图或文字说明。
- 给出分阶段迁移任务，不要求一次性重构。
- 明确每次迁移后的验证命令和人工检查点。
- 不在本任务中实施大规模代码迁移。
