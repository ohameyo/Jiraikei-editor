# Web 性能基线与真机验收清单

## 优先级
P1，承接「网页制作方向与 App 封装方案」。

## 任务目的
为 Web 版本建立可重复的性能和兼容性判断依据，避免只凭主观手感决定是否继续优化、做 PWA 或封装 App。

## 范围
- 首屏加载和资源请求记录。
- 上传图片后的首次清晰渲染耗时。
- 滤镜滑杆拖动、松手后清晰渲染耗时。
- 图层移动、缩放、旋转的跟手表现。
- 导出预览和下载耗时。
- Safari、Chrome、微信/小红书内嵌浏览器、低端 Android WebView 兼容性。

## 产出
- 真机/浏览器验收清单。
- 关键性能指标记录模板。
- 当前版本性能基线。
- 明确哪些问题属于 Web 内部优化，哪些可能需要 PWA/App 壳能力。

## 验收标准
- 至少覆盖 PC Chrome、移动端 Safari、移动端 Chrome、一个内嵌浏览器。
- 每个环境记录导入、编辑、导出是否可完成。
- 明确 P0/P1 性能问题清单和复测方法。
